# Desktop parity matrix

Phase 1 deliverable: every current command and workflow, classified as
**Preserve**, **Intentional desktop change**, or **Existing bug to fix**, with
the desktop contract it implies and the phase that implements it.

Source of truth is the code (`Sources/PRReviewKit`), reconciled against
`README.md`. Where the README promises behavior the code does not deliver, the
behavior is classified as a bug, not as preserved behavior.

Legend for phases: 1 = Phase 1 characterization, 2 = harden core, 3 =
persistence, 5 = read-only UI, 6 = workflows, 7 = native interaction, 8 =
onboarding, 10 = release/cleanup.
